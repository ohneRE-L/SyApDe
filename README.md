# Служба поддержки и тикет-система (Helpdesk / Service Desk)

Репозиторий содержит материалы лабораторной работы по проектированию архитектуры программного обеспечения тикет-системы технической поддержки с учетом ролевой модели, соглашений об уровне обслуживания (SLA) и сквозной истории коммуникаций.

---

## Структура репозитория

```text
.
├── README.md               # Общее описание проекта, структуры и инструкций
├── ARCHITECTURE.md         # Архитектурный отчет (Use Cases, C4 Container, ERD в 3NF, спецификация БД)
└── diagrams/               # Исходные файлы архитектурных диаграмм
    ├── c4_container.png   # C4 Container
    └── erd.png         # ER-диаграмма базы данных

```
Назначение проекта 

Система решает задачи автоматизации сервисного обслуживания:Прием, классификация и маршрутизация обращений клиентов.  Контроль дедлайнов реагирования и решения инцидентов в соответствии с матрицей SLA.  Ведение единой хронологической ленты диалога с поддержкой файлов-вложений и внутренних служебных заметок.  Аудит нарушений регламентов обслуживания для аналитики качества сервиса.
